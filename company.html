Company

Named for the brain's own relay station.

The thalamus filters and routes incoming signal to the right part of the brain for processing. We think clinical AI needs the same layer: something that sits between raw patient data and every agent trying to reason over it.

Why now

Millions of narrow-task clinical agents are coming.

Each one needs a precise slice of a patient's history for its task, not the full longitudinal record. Handing an agent everything doesn't make it smarter. It makes it slower, more expensive, and more likely to hallucinate.

Wearables and patient check-ins with agents are only going to add to that volume. The teams building clinical agents shouldn't each have to solve context filtering on their own.

Where this came from

Built out of a problem we hit directly.

Turning each incoming report into a summary, then merging summaries into one master record, kept losing clinical quality, causing hallucination, added cost and added latency. It became clear every team building a clinical agent runs into the same wall. Thalamus is the infrastructure layer we built to solve it once, properly, instead of every team solving it badly on their own.

What we believe

A short list of positions the product is built on.

  • Context should be compiled per task, not dumped in full: more history is not more signal.
  • Every data point an agent sees should trace back to a real source document.
  • Conflicting data should be surfaced explicitly, never silently resolved by the agent.
  • Patient state should update the moment new data arrives, not on a batch schedule.
  • This is infrastructure for the companies building agents, not a product for hospitals or patients directly.
